枚举（Enum）是 TypeScript 中非常有用的特性，它允许我们定义一组命名常量。枚举可以使得代码更易读、更易维护，可以用有意义的名称替代"魔术数字"。

## (一) 数字枚举

默认情况下，枚举从 0 开始编号。

**运行结果：**

```typescript
方向: 0
方向名称: Up
```

## (二) 手动赋值

可以手动为枚举成员指定值。

**运行结果：**运

```typescript
状态: 1
状态名称: Success
```

## (三) 字符串枚举

字符串枚举每个成员都必须有字符串字面量值。

**运行结果：**

```typescript
消息: SUCCESS
```

## (四) 常量枚举

使用 `const` 修饰的枚举会在编译时内联，生成更优化的代码。

## (五) 异构枚举

枚举可以混合数字和字符串值，但不推荐使用。

## (六) 枚举成员类型

当枚举成员都是字面量值时，成员类型可以作为类型使用。

## (七) 运行时常量枚举

普通枚举在运行时保留为真实对象。

**运行结果：**

```typescript
文件访问: 6
```

## (八) 总结

- **数字枚举：**默认从 0 开始，可手动赋值
- **字符串枚举：**每个成员必须是字符串字面量
- **常量枚举：**使用 const，编译时内联
- **异构枚举：**混合数字和字符串，不推荐
- **成员类型：**字面量枚举成员可用作类型
