# 一、网络异步图片加载

## (一) 思路

当ListView中列表项显示的图片数据来自于网络时，要使用子线程去异步加载。由于需要把来制网络下载的图片显示出来，所以应该使用Handler或AsyncTask是最方便的，再因为AsyncTask中有线程池的封装，所以一般都选择使用AsyncTask。

## (二) 步骤

1. 使用ListView + 自定义Adapter显示图片 在getView回调中。
2. 启动AsyncTask，从服务器获取图片文件数据。
3. 将图片显示到ListView中。

问题：没有加入缓存机制，每次都需要从获取图网络获取图片数据，效果差

## (三) 源码（AsyncTask中部分）

```
     * 4.从响应中获取数据*/

    HttpClient client = new DefaultHttpClient();
    HttpGet reqGet = new HttpGet(params[0]);

        HttpResponse rsp = client.execute(reqGet);
        if(rsp.getStatusLine().getStatusCode() == HttpStatus.SC_OK) {

            //使用输入流创建Bitmap对象
            bmp = BitmapFactory.decodeStream(is);
        } else {
        }
    } catch (Exception e) {
        e.printStackTrace();
    }
    return bmp;
}

@Override
protected void onPostExecute(Bitmap result) {
    super.onPostExecute(result);
    //在该方法中，设置imageView的内容
    if(result != null) {
        iv.setImageBitmap(result);
    } else {
        //图片获取失败
    }
}
```

```
//二级，尝试从sdcard获取，保存到内存
else if ((new File(filePath)).exists() && (new File(filePath)).isFile()) {
    //判断文件是否存在，文件是否是文件
```

## (四) 源码（只有异步任务中实现二级缓存的代码）

```
public class ImageLoadTask extends AsyncTask<String, Void, Void> {

    MainActivity activity;
    int pos;
    ImageView iv;

    // 参数1：MainActivity，用来获取数据源
    // 参数2：执行该异步任务的行号
    // 参数3：该行的ImageView控件
    public ImageLoadTask(MainActivity activity, int pos, ImageView iv) {
        this.activity = activity;
        this.pos = pos;
        this.iv = iv;
    }

    @Override
    // 发送httpGet请求，获取图片内容
    protected Void doInBackground(String... params) {
        HttpClient client = new DefaultHttpClient();   //1. 创建HttpClient
        HttpGet reqGet = new HttpGet(params[0]);       //2.创建Get请求
        try {
            HttpResponse rsp = client.execute(reqGet); //3. 发送请求，获取响应
            if (rsp.getStatusLine().getStatusCode() == HttpStatus.SC_OK) {
                // 4.从输入流中获取内容，并转换成Bitmap对象
                InputStream is = rsp.getEntity().getContent();
                Bitmap bm = BitmapFactory.decodeStream(is);

                // 判断缓存目录是否存在，如果不存在就创建一个
                if (!new File(MainActivity.IMG_CACHE_PATH).exists()
                        || !new File(MainActivity.IMG_CACHE_PATH).isDirectory()) {
                    new File(MainActivity.IMG_CACHE_PATH).mkdirs();   // 创建目录
                }

                // 1.图片保存到sd卡中
                bm.compress(
                        // 这个方法把图片压缩成流保存（保存格式，质量0最低100最高，流）
                        CompressFormat.JPEG,
                        100,
                        new FileOutputStream(MainActivity.IMG_CACHE_PATH
                                + params[0].substring(params[0].lastIndexOf("/") + 1)));

                activity.data.get(pos).bmp = new SoftReference<Bitmap>(bm);  //2.保存到软引用中
                bm = null;   //注意将硬引用bm赋为空，不然软引用对象不会被销毁
            } else {
            }  //SoftReference<Bitmap>bmp; MainActivity中的Javabean中
        } catch (Exception e) {
            e.printStackTrace();
        }
        return null;
    }

    @Override
    // 显示图片到ImageView上
    protected void onPostExecute(Void result) {
        super.onPostExecute(result);
        iv.setImageBitmap(activity.data.get(pos).bmp.get());
    }
}
```
