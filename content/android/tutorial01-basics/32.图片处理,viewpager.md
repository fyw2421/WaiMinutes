# 一、图片处理

## (一) 图片变换

### 1. Matrix

Matrix：用来描述矩阵。 将原bitmap对象，按照matrix的规定变形，生成新bitmap对象

```
bitmap = Bitmap.createBitmap(bitmap, 0, 0, bitmap.getWidth(), 	bitmap.getHeight(), matrix, true);
```

- 参数1：需要变形的bitmap对象
- 参数2,3：从原bitmap中取样的起始坐标
- 参数4,5：原图的宽，高像素个数
- 参数6：描述变形的Matrix对象
- 参数7：原图是否需要被过滤

### 2. 放大

```
Bitmap bm10 = BitmapFactory.decodeResource(getResources(), R.drawable.a, null);

Matrix m = new Matrix();

m.setScale(2, 2);

//设置x，y上的缩放比例

Bitmap bm1 = Bitmap.createBitmap(bm10,
        0, 0,  bm10.getWidth(), bm10.getHeight(),
        m,
        true
        );

iv.setImageBitmap(bm1);
```

### 3. 旋转

```
Bitmap bm20 = BitmapFactory.decodeResource(getResources(), R.drawable.a, null);

Matrix m2 = new Matrix();

m2.setRotate(45); //设置旋转角度

Bitmap bm2 = Bitmap.createBitmap(bm20, 0, 0, bm20.getWidth(), bm20.getHeight(),
        m2, true);

iv.setImageBitmap(bm2);
```

### 4. 扭曲

```
Bitmap bm30 = BitmapFactory.decodeResource(getResources(), R.drawable.a, null);

Matrix m3 = new Matrix();

m3.setSkew(0.5f, 0.5f); //设置x，y上扭曲系数，扭曲会使图片变大

Bitmap bm3 = Bitmap.createBitmap(bm30, 0, 0, bm30.getWidth(), bm30.getHeight(), m3, true);

iv.setImageBitmap(bm3);
```

### 5. 裁剪

对Bitmap进行裁剪。裁剪的区域是相前对原位图左上角为原点的坐标来决定即(x, y)与(width,height)

```
Bitmap bm40 = BitmapFactory.decodeResource(getResources(), R.drawable.a, null);

Bitmap bm4 = Bitmap.createBitmap(bm40, 20, 20, 50, 50, null, true);

iv.setImageBitmap(bm4);
```

## (三) 处理图片OOM

OOM就是内存溢出，即Out Of Memory。也就是说内存占有量超过了VM所分配的最大。

实现开发中OOM发生最多的地方就是Bitmap造成的。

### 1. 办法一：软引用（二级缓存）

解决加载大量图片而出现的OOM问题。但是，若一张图片就大到OOM，它无法解决。比如一张要编码成2M左右的图片，被解码后可以达到10M左右的数据

### 2. 办法二：回收Bitmap

对于不在使用Bitmap对象，一定要resycle() 示例：

```
if(!bm.isResycled) { //判断位图是否已经回收
    //设置采样
    bm = null;
}
```

### 3. 办法三：二次采样

BitmapFactory.Options中有很多属性供我们修改

- inSampleSize：采样频率。当值为1，获取原图的子图像矩阵。设置为4，表示宽和高都变成原图的1/4，因此总像素个数将为原图的1/16。 （只能为2的次方）
- inPreferredConfig：每个像素的存储方式，有四个可选值，默认为ARGB_8888（也就是说一个像素32bit） ALPHA_8；ARGB_4444；RGB_565 ；ARGB_8888

```
Options ops = new Options();

ops.inSampleSize = 4;  //采样频率为4，宽和高都变成原图的1/4。

ops.inPreferredConfig = Bitmap.Config.ARGB_4444; //每个像素用16bit存储

Bitmap bm = BitmapFactory.decodeStream(getAssets().open("b.jpg"), null, ops);//null是外边距

iv.setImageBitmap(bm);
```

### 4. 办法四：优先调用C获取BItmap

先通过BitmapFactory.decodeStream方法，创建bitmap该方法是使用C直接完成的，从而节省了java层的空间

# 二、ViewPager（向导页面）

## (一) 控件介绍：android.support.v4.view.ViewPager

使用ViewPager，开发者可以实现侧滑屏幕来达到界面切换的效果，需要为ViewPager配置PagerAdapter，PagerAdapter能够生成要显示的界面（和ListView对照）。

我们可以把ViewPager当做展现界面的容器，PagerAdapter会根据用户的操作（侧滑），将对应的界面并放置到ViewPager中。

PS: GuideActivity要注册，布局文件中添加ViewPager容器，layout中多个Page布局（XML）.

activity_main.xml 添加控件：

```
<android.support.v4.view.ViewPager
    android:id="@+id/vp_main"
    android:layout_width="match_parent"
    android:layout_height="match_parent" />
```

AndroidManifest.xml 注册Activity：

```
<activity android:name="com.example.day29_hw.GuideActivity" >

    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.LAUNCHER" />
    </intent-filter>

</activity>
```

## (二) 作用原理

可以把ViewPager看成一个数组，数组中存放的是可能显示的View，

Adapter负责将View添加到ViewPager（instantiateItem），并将离当前显示View距离大于1的View从ViewPager移除（destroyItem）。

比如，当前显示page1，此时page2和page1相邻，所以也会被添加到ViewPager中。滑动到page2时，因为page1和page3都和page2相邻，所以，page3会被添加到ViewPager中。滑动到page3时，因为page1和page3的距离为2，因此，会被从ViewPager中移除。

## (三) 自定义PageAdapter

(与fragment连用必须用V4包里的fragment)

创建类MyPagerAdapter继承于PagerAdapter，重写4个方法：

```
class MyAdapter extends PagerAdapter {
    public int getCount() {
        //返回总页数
        return pages.size();
    }

    public boolean isViewFromObject(View arg0, Object arg1) {
        //判断View和Object是否相等
        return arg0 == arg1;
    }

    //将指定页添加到ViewGroup中，并返回此页的引用。
    public Object instantiateItem(ViewGroup container, int position) {
        //需要显示页时被回调
        container.addView(pages.get(position));
        //需要先添加到container中，然后返回
        return pages.get(position);
    }

    //	移除指定位置的页
    //当页需要被销毁时回调
    public void destroyItem(ViewGroup container, int position, Object object) {
        //			super.destroyItem(container, position, object); 这个不能写否则会报错
        container.removeView(pages.get(position));
    }
}
```

## (四) 实现向导页面跳转到主页面

```
public class GuideActivity extends Activity {

    //注意在Manifest中注册

    //创建View数组，该数组中的View对象会被显示到ViewPager中

    ArrayList<View> pages = new ArrayList<View>();

    ViewPager vp;

    Button btn;

    View page0, page1, page2;

    //每一个page都需要在layout中写xml布局文件

    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.GuideActivity_main);

        //将三个page的布局文件转换成View对象，并保存到pages中

        page0 = LayoutInflater.from(this).inflate(R.layout.page0, null);
        page1 = LayoutInflater.from(this).inflate(R.layout.page1, null);
        page2 = LayoutInflater.from(this).inflate(R.layout.page2, null);

        pages.add(page0);
        pages.add(page1);
        pages.add(page2);

        //一定要在page2中通过反射获取btn不然会空指针

        btn = (Button) page2.findViewById(R.id.btn_enter_page2);

        btn.setOnClickListener(new OnClickListener() {
            public void onClick(View v) {
                //启动MainActivity

                startActivity(new Intent(GuideActivity.this, MainActivity.class));
                finish();
                //销毁本Activicty
            }
        });

        vp = (ViewPager)findViewById(R.id.vp_main);
        vp.setAdapter(new MyAdapter());
        //给viewPager设置adapter
    }

    class MyAdapter extends PagerAdapter {

        @Override
        //返回总页数
        public int getCount() {
            return pages.size();
        }

        @Override
        //判断arg0是否==arg1
        public boolean isViewFromObject(View arg0, Object arg1) {
            // TODO Auto-generated method stub
            return arg0 == arg1;
        }

        @Override
        //当页需要被销毁时回调
        public void destroyItem(ViewGroup container, int position, Object object) {
            //super.destroyItem(container, position, object);
            container.removeView(pages.get(position));
        }

        @Override
        //需要显示页时被回调
        public Object instantiateItem(ViewGroup container, int position) {
            //需要先添加到container中，然后返回
            container.addView(pages.get(position));
            return pages.get(position);
        }

    }

}
```
