# 一、实现方式

1. 异步线程（AsyncTask，Handler）
2. 联网
3. 数据解析（JSON，XML）
4. ListView

Android中的所有网络操作都必须在子线程中完成！

# 二、ListView+AsyncTask加载网络数据——JSON

功能：网络异步加载JSON数据，并解析，然后显示到ListView中

## (一) 步骤

1. 创建AsyncTask对象，在DoInBackground方法中，向服务器发送请求，获取数据

   1.1 创建HttpClient对象

   1.2 创建请求对象HttpGet

   1.3 通过HttpClient对象发送请求，并获取返回的HttpResponse

   1.4 从HttpResponse对象中获取一个输入流，HttpResponse.getEntity().getContent()

   1.5 从输入流中读取byte数组，然后转换成String，并保存

2. 创建ListView中每一行的布局文件xml

3. 创建数据源

4. 创建ListView对象

5. 创建自定义Adapter，BaseAdapter

   5.1 两层优化（View对象的复用、减少findViewById次数）

6. 将前面获取的json字符串解析，获取内容，并显示到ListView上

## (二) 代码

```
public class MainActivity extends Activity {

    public static final String MY_URL = "http://192.168.95.1:8080/Day_24_Server/MyServlet";

    //创建JavaBEAN,代表每一行中显示的数据
    class Data {
        String name, age, gender;

        public Data(String name, String age, String gender) {
            super();
            this.name = name;
            this.age = age;
            this.gender = gender;
        }
    }

    //创建数据源
    ArrayList<Data> data = new ArrayList<Data>();
    ListView lv;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        lv = (ListView)findViewById(R.id.lv_main);

        //当程序运行时，发送Get请求到服务器，获取json数据
        new MyTask().execute(MY_URL);
    }

    class MyTask extends AsyncTask<String, Void, Boolean> {
        @Override
        protected Boolean doInBackground(String... params) {
            //发送Get请求
            //创建HttpClient对象
            HttpClient client = new DefaultHttpClient();
            //创建请求对象
            HttpGet reqGet = new HttpGet(params[0]);
            try {
                //发送请求
                HttpResponse rsp = client.execute(reqGet);
                //获取rsp中的数据
                if(rsp.getStatusLine().getStatusCode() == HttpStatus.SC_OK) {
                    InputStream is = rsp.getEntity().getContent();
                    //从输入流中读取数据
                    String str = "";
                    int n = -1;
                    byte[] tmp = new byte[1024];
                    while((n = is.read(tmp)) != -1) {
                        //将读到的byte数组转成String
                        str += new String(tmp, 0, n);
                    }
                    //解析json
                    //根据String创建json对象
                    JSONObject data1 = new JSONObject(str);
                    JSONArray arr = data1.getJSONArray("data");
                    for(int i = 0; i < arr.length(); i ++) {
                        JSONObject jobj = arr.getJSONObject(i);
                        String name = jobj.getString("name");
                        String age = jobj.getString("age");
                        String gender = jobj.getString("gender");
                        //保存到data中
                        data.add(new Data(name, age, gender));
                    }
                } else {
                    //失败
                }
            } catch (Exception e) {
                e.printStackTrace();
            }
            return null;
        }

        @Override
        protected void onPreExecute() {
            super.onPreExecute();
        }

        @Override
        protected void onPostExecute(Boolean result) {
            super.onPostExecute(result);
            lv.setAdapter(new MyAdapter());
        }

        @Override
        protected void onProgressUpdate(Void... values) {
            super.onProgressUpdate(values);
        }
    }

    class MyAdapter extends BaseAdapter {
        @Override
        public int getCount() {
            return data.size();
        }

        @Override
        public Object getItem(int position) {
            return data.get(position);
        }

        @Override
        public long getItemId(int position) {
            return 0;
        }

        @Override
        public View getView(int position, View convertView, ViewGroup parent) {
            //使用两层优化，复用View对象，以及减少findViewById的次数
            ViewHolder mHolder;
            if(convertView == null) {
                convertView = LayoutInflater.from(MainActivity.this).inflate(R.layout.item, null);
                TextView tvName = (TextView)convertView.findViewById(R.id.tv_name_item);
                TextView tvAge = (TextView)convertView.findViewById(R.id.tv_age_item);
                TextView tvGender = (TextView)convertView.findViewById(R.id.tv_gender_item);
                mHolder = new ViewHolder(tvName, tvAge, tvGender);
                //将Viewholder保存到View中
                convertView.setTag(mHolder);
            } else {
                mHolder = (ViewHolder)convertView.getTag();
            }

            mHolder.tvName.setText(data.get(position).name);
            mHolder.tvAge.setText(data.get(position).age);
            mHolder.tvGender.setText(data.get(position).gender);

            return convertView;
        }
    }

    class ViewHolder {
        TextView tvName, tvAge, tvGender;

        public ViewHolder(TextView tvName, TextView tvAge, TextView tvGender) {
            super();
            this.tvName = tvName;
            this.tvAge = tvAge;
            this.tvGender = tvGender;
        }
    }
}
```
