# 一、Notification介绍

Notification是显示在手机状态的消息--手机状态栏位于手机屏幕的最上方， 那里一般显示了手机当前的网络状态， 电池状态， 事件等。  Notification所代表的是一种具有全局效果的通知， 程序一般通过NotificationManager服务来发送Notification。

# 二、Notification使用方式

一、调用getSystemService(NOTIFICATION_SERVICE)的方法获取Notification服务：

```
NotificationManager notificationManager = (NotificationManager) getSystemService(NOTIFICATION_SERVICE);
```

二，获取Notification对象

```
Notification notify = new Notification();
final int NOTIFICATION_ID =1001;
```

三，设置各种参数

```
//为Notification设置图标，该图标显示在状态栏
notify.icon = R.drawable.notify;
//为Notification设置文本内容，该文本会显示在状态栏
notify.tickerText = "启动其他Activity的通知";
//为Notification设置发送时间
notify.when = System.currentTimeMillis();
//为Notification设置声音
notify.defaults = Notification.DEFAULT_SOUND;
//为Notification设置默认声音、默认振动、默认闪光灯
notify.defaults = Notification.DEFAULT_ALL;
```

四，设置事件信息

```
//创建一个启动其他Activity的Intent
Intent intent = new Intent(NotificationTest.this , OtherActivity.class);
PendingIntent pi = PendingIntent.getActivity(NotificationTest.this, 0, intent, 0);
notify.setLatestEventInfo(NotificationTest.this, "普通通知","点击查看", pi);
```
