通过 `ContentResolver` 查询通讯录 URI，用 `Cursor` 逐条读取联系人的姓名与号码：

```
Cursor cursor = context.getContentResolver()
        .query(Phone.CONTENT_URI, null, null, null, null);

cursor.moveToFirst();
while (!cursor.isAfterLast()) {
    int nameIndex = cursor.getColumnIndex(Phone.DISPLAY_NAME);
    int numberIndex = cursor.getColumnIndex(Phone.NUMBER);

    person p = new person();
    p.setName(cursor.getString(nameIndex));
    p.setNumber(cursor.getString(numberIndex));
    persons.add(p);

    cursor.moveToNext();
}
```
