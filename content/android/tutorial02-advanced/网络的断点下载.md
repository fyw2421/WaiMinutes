当某次下载文件时下载得不完全，再次下载时，根据上次的下载进度，对此次网络连接设置下载区间：

```
connection.setRequestProperty("Range", "bytes=" + start + "-" + end);
```

在这种设置下，网络连接成功时，连接状态是 `HttpStatus.SC_PARTIAL_CONTENT`。

对于接受网络数据的本地文件，也要设置它的写入位置，这里要用：

```
RandomAccessFile accessFile = new RandomAccessFile(file, "rwd");
accessFile.seekTo(start);
```

数据将从 start 位置开始再次写入到文件。
