熟练掌握绘图方法，灵活应用，就可以做出小游戏了。曾经只用了绘制圆和位图的方法，加上最小路径搜索算法，做了一个仿神经猫的游戏。

# 一、矩形

- `drawRect(float x1, float y1, float x2, float y2, Paint paint)`：绘制左上角顶点为 (x1, y1)、右下角顶点为 (x2, y2) 的矩形
- `drawRect(Rect rect, Paint paint)`：绘制一个指定的矩形

# 二、多边形

`drawVertices(VertexMode mode, int count, float[] pts, 0, null, 0, null, 0, null, 0, 0, Paint paint)` 用于绘制一个多边形，其中 count 为坐标的个数，等于 pts 的大小。理论上此方法可以绘制矩形，实际上此方法的本质是绘制无数个三角形，具体的参数大家可以自行查阅官方 API 文档。

# 三、弧线

`drawArc(Rect rect, float startAngle, float sweepAngle, bool useCenter, Paint paint)` 用于在矩形 rect 内部（此矩形并不会绘制）绘制一段弧：起始角度为 startAngle，结束角度为 sweepAngle，`useCenter` 决定这段弧是否会显示起点与终点的连线。当 `sweepAngle - startAngle >= 360` 时，绘制效果是一个椭圆；在正方形内绘制时，是个圆弧。

# 四、圆

`drawCircle(float cx, float cy, float r, Paint paint)` 将绘制一个以 (cx, cy) 为圆心、r 为半径的圆。

# 五、文字

`drawText(String s, float x, float y, Paint paint)` 将在 (x, y) 处绘制字符串 s。注意这个方法绘制出的文字效果是以 (x, y) 为这个字符串的左下角的坐标。

# 六、位图

- `drawBitmap(Bitmap bitmap, float left, float top, Paint paint)`：以 (left, top) 为左上角的坐标进行绘制
- `drawBitmap(Bitmap bitmap, Rect src, Rect dst, Paint paint)`：这里的 src 可以为 null，绘制的图形将局限在 dst 内
