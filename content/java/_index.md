Java 学习笔记，综合多份经典教程与官方文档整理，按学习顺序编排为 20 篇，可从头顺读，也可按需检索：

- **01–07 基础** — 语言概览、快速入门、面向对象、异常处理、反射、注解、泛型
- **08–13 进阶** — 集合框架、IO 与 NIO、日期与时间、单元测试、正则表达式、加密与安全
- **14–20 实战** — 多线程、Maven、网络编程、XML 与 JSON、JDBC、函数式编程、设计模式

每一篇都配有示例代码、易错点说明与参考来源。内容为原创整理：章节顺序参考了 [廖雪峰 Java 教程](https://liaoxuefeng.com/books/java/) 的编排，正文则依据 [Java 官方教程](https://docs.oracle.com/javase/tutorial/)、[Java 语言规范 JLS](https://docs.oracle.com/javase/specs/jls/se22/html/index.html) 与《Java 核心技术》等公开资料写成，并对各版本的差异与常见坑做了标注。各篇末尾另附具体参考来源。
