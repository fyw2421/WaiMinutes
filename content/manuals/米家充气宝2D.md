# 一、产品概述

Xiaomi Portable Electric Air Compressor 2 可为部分自行车、摩托车、汽车、电动滑板车的轮胎以及球类充气。

## (一) 部件名称

按手册部件图自上而下：

- 美式气嘴转接头（Schrader Valve Adapter）
- 高压气管
- 气管收纳仓
- 灯
- 气管接口
- 显示屏
- 散热孔
- + 按钮
- 启停按钮
- 灯开关按钮
- − 按钮
- 模式按钮
- 充电口

## (二) 配件

- 法式气嘴转接头（Presta Valve Adapter）
- 气针转接头（Needle Valve Adapter）
- 快速接头（Quick Connect Valve Adapter）
- 收纳袋（Storage Pouch）

注：收纳袋内有一个内袋，用于存放法式气嘴转接头、气针转接头与快速接头。

# 二、电量指示与充电

## (一) 电量指示

- 电量 ≥ 75%：满格图标
- 75% > 电量 ≥ 50%：三格图标
- 50% > 电量 ≥ 25%：两格图标
- 电量 < 25%：需要充电

## (二) 充电

首次使用前请将充气宝充满电。将充电线连接至兼容的 5V USB 电源适配器，为充气宝充电。

充电状态：

- 电量 < 25%：一格闪烁
- 50% > 电量 ≥ 25%：两格闪烁
- 75% > 电量 ≥ 50%：三格闪烁
- 99% ≥ 电量 ≥ 75%：四格闪烁
- 电量 = 100%：满格常亮 20 秒后熄灭

注意：

- 充电时不能使用充气宝。
- 充电时间约3小时

# 三、开机与关机

## (一) 开机

- 将高压气管从收纳仓中取出，充气宝自动开机。
- 开机后若 3 分钟未使用，充气宝自动关机。
- 若高压气管未放回收纳仓时充气宝自动关机，长按启停按钮可重新开机。

## (二) 关机

- 将高压气管插回收纳仓，充气宝关机。
- 开机状态下长按启停按钮关机。

# 四、连接高压气管与气嘴

## (一) 美式气嘴（Schrader）

山地车、电动车、摩托车、电动滑板车与汽车的轮胎使用美式气嘴。

- 充气：将美式气嘴接到高压气管上的美式气嘴转接头，即可开始充气。
- 放气：使用合适的工具（如 4 mm 内六角扳手）按下气门芯即可放气。

## (二) 法式气嘴转接头（Presta）

公路车与部分山地车充气需要使用标配的法式气嘴转接头。

- 充气：把法式气嘴转接头接到高压气管上的美式气嘴转接头；拧开轮胎的法式气嘴；将法式气嘴接到转接头即可开始充气。
- 放气：拧下法式气嘴的螺纹防尘帽，向下按压防尘帽即可放气。

## (三) 气针转接头

篮球、足球等球类充气需要使用标配的气针转接头。

- 充气：将气针转接头拧到美式气嘴转接头上，把气针插入球的气门即可开始充气。
- 放气：将气针转接头插入球的气门即可放气。

## (四) 快速接头

山地车、电动车、摩托车、电动滑板车与汽车的轮胎使用美式气嘴。

- 充气：把快速接头接到高压气管上的美式气嘴转接头；将快速接头接到美式气嘴上，按图示方向按下扳手锁定，即可开始充气。
- 放气：将快速接头接到美式气嘴上，向下按压快速接头即可放气。

# 五、气压

充气宝开机且高压气管接入被充物后，屏幕自动显示当前气压。

为确保安全、避免过充引发爆炸造成人身伤害与财产损失，充气前请参阅被充物附带的说明或相关指引，确定所需气压。

- 轮胎：汽车、自行车、电动滑板车与摩托车轮胎的建议充气压力标在胎侧；汽车轮胎的建议充气压力还标在驾驶侧车门框上。与载重相关的建议气压请参阅车辆说明书。
- 球类：足球、篮球、排球及其他球类的建议充气压力标在球的气门附近。

1 bar ≈ 14.5 psi，1 bar = 100 kPa，1 psi ≈ 6.89 kPa。

气压参考表：

| 类别 | 类型 | 建议气压范围 |
| --- | --- | --- |
| 自行车 | 12″、14″、16″ 自行车轮胎 | 30–50 psi / 2.0–3.4 bar |
| 自行车 | 20″、22″、24″ 自行车轮胎 | 40–50 psi / 2.7–3.4 bar |
| 自行车 | 26″、27.5″、29″ 山地车轮胎 | 45–65 psi / 3.1–4.5 bar |
| 自行车 | 小米电动滑板车轮胎 | 45–60 psi / 3.1–4.1 bar |
| 自行车 | 700c 公路车开口胎 | 100–130 psi / 6.9–9.0 bar |
| 自行车 | 700c 公路车管胎 | 120–145 psi / 8.3–10 bar |
| 摩托车 | 摩托车或电动滑板车轮胎 | 1.8–3.0 bar / 26–43.5 psi |
| 汽车 | 汽车轮胎 | 2.2–2.8 bar / 32–40.6 psi |
| 球类 | 篮球 | 7–9 psi / 0.48–0.62 bar |
| 球类 | 足球 | 8–16 psi / 0.55–1.1 bar |
| 球类 | 排球 | 4–5 psi / 0.28–0.34 bar |
| 球类 | 足球 | 12–14 psi / 0.83–0.97 bar |

注：气压范围仅供参考，请以被充物的说明或手册为准。原手册"球类"一栏中 Football 出现两次，数值分别为 8–16 psi 与 12–14 psi。

# 六、充气

**开始充气**：按一下启停按钮开始充气，充气过程中屏幕实时显示压力变化。

**停止充气**：气压达到预设值后充气宝自动停止充气；充气过程中也可随时按一下启停按钮手动停止。

**注意**：气球、沙滩球、泳圈等物品所需的气压低于充气宝的最低气压范围，无法通过预设气压自动停止充气，只能手动小心充气。

**电量信息**：在 25°C 环境下满电空载运行，电池约可用** 25 **分钟；在重负载或更低环境温度下使用可能缩短电池寿命。

**拆卸**：充气后气嘴转接头与气管的温度较高，从被充物上取下充气宝时请小心避免烫伤。断开时会有少量空气从气门漏出，为减少气压损失，请尽快将充气宝从气门上取下。

# 七、预设压力与模式表

## (一) 切换模式

按模式按钮可在屏幕上循环切换六种充气模式。充气前长按模式按钮，可在 psi 与 bar 之间切换气压单位。

手动模式：屏幕左侧没有模式图标，可自由调节预设气压，数值与单位会被记忆。可调范围：3–150 psi / 0.2–10.3 bar。

模式表：

| 模式 | 默认预设 | 可调范围 |
| --- | --- | --- |
| 手动模式 | 自由设定，数值与单位记忆 | 3–150 psi / 0.2–10.3 bar |
| 自行车模式 | 45 psi | 30–65 psi |
| 摩托车模式 | 2.4 bar | 1.8–3.0 bar |
| 汽车模式 | 2.5 bar | 1.8–3.0 bar |
| 电动滑板车模式 | 50 psi | 45–60 psi |
| 球类模式 | 8 psi | 4–16 psi |

## (二) 调节预设压力

- 选定充气模式后，按 + 或 − 按钮增减预设气压值；长按 + 或 − 按钮可快速调节气压值。
- 调节预设气压时数字闪烁；显示实时气压时数字停止闪烁。

## (三) 灯

按灯开关按钮循环切换：开灯 → SOS 灯 → 关灯。
